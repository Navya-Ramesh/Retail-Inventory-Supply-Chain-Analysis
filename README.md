# 📊 Retail Inventory & Supply Chain Analysis – Power BI

## 📌 Project Overview

This project analyzes retail sales, product performance, inventory management, and supply chain operations using Power BI. I developed an interactive dashboard to deliver meaningful business insights and support data-driven decision-making.

## 🎯 Objectives

* Analyze sales and revenue performance.
* Identify top-performing products and categories.
* Monitor inventory levels and stock availability.
* Analyze supplier and warehouse performance.
* Identify inventory and supply chain issues.

## 🛠️ Tools & Technologies

* SQL
* Snowflake
* Microsoft Power BI
* DAX
* Power Query
* Data Modeling

## 📈 Dashboard Pages

### 1. Sales Overview

* Revenue by category
* Monthly revenue trends
* Regional sales performance

### 2. Product Performance

* Top 10 products by units sold
* Product-wise sales analysis
* Category-wise performance

### 3. Inventory Analysis

* Stock on hand
* Inventory levels
* Reorder level monitoring
* Stock availability

### 4. Supply Chain Analysis

* Supplier performance
* Warehouse analysis
* Stockout monitoring
* Supply chain insights

## ✨ Key Features

* Interactive slicers and filters

* Data modeling and relationships

* Interactive visualizations
